# Guide to testing lion for agents

## Unit-Tests

General guidelines for creating unit tests for Project Lion

## End-To-End (e2e) Tests
Lion is a command line tool and is therefore well suited for testing by agents executing commands.

Is described

* the one-time setup of a test base in docker
* the instantiation of a test container
* Preparation of the test run
* carrying out the test
* Preparation of the results.
